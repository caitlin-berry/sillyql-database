# SillyQL | Relational Database Engine

**C++ | Data Structures | Database Systems | Query Optimization**

## Overview
SillyQL is an in-memory relational database engine developed in C++ that supports SQL-like commands for creating, modifying, and querying tables. The project explores core database concepts, including relational data management, indexing, and efficient query processing.

## Key Features
- **Database Management:** Create and remove tables with typed columns.
- **Data Manipulation:** Insert and delete records through a command-line interface.
- **Query Processing:** Retrieve selected columns, filter records using comparison operators, and join tables based on matching values.
- **Indexing:** Support hash-based and binary search tree-based indices to improve data retrieval.
- **Performance:** Support a quiet mode that minimizes output during large-scale testing.

## Technical Highlights
- Developed the database engine using C++ and object-oriented design.
- Used vectors, hash maps, and ordered maps to support different storage and lookup operations.
- Implemented SQL-like command processing for table management and querying.
- Maintained indices as table contents changed.
- Explored tradeoffs between different data structures and query operations.

## Skills Demonstrated
C++, STL, data structures, hash tables, binary search trees, relational databases, command parsing, and algorithmic optimization.
